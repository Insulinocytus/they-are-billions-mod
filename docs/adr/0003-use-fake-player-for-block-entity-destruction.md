# ADR-0003：使用 FakePlayer 破坏方块

- 状态：已接受
- 日期：2026-09-06

## 背景

模组要求僵尸以玩家空手挖掘速度破坏方块，并尽量遵守原版与其他模组定义的权限、工具及掉落规则。跨加载器不存在能够安全提取所有方块实体“内容物”的统一接口。

## 决策

- 所有方块均由固定模组身份、空手、生存模式的 FakePlayer 走完整玩家破坏流程。
- 接受方块自身规则产生的完整结果，包括方块本体、内容物、经验或保存了内部数据的方块物品。
- 所有破坏共享一个稳定的模组专属 UUID 与 GameProfile。Fabric 与 NeoForge 分别提供最小 FakePlayer 工厂，并按 `ServerLevel` 缓存实体实例；不冒用被追猎玩家的身份或权限。
- 始终先检查 `mobGriefing`，并让加载器的标准玩家破坏事件和可用的实体破坏事件拒绝操作。
- 挖掘耗时按无状态效果、站在地面且不在水中的空手生存玩家计算。
- 尸潮成员的原版破门 Goal 被禁用，门统一走同一破坏与权限流程。
- 权限拒绝结果暂时缓存；实体尝试绕路，没有替代路线时每五秒最多重新检查一次，避免重复触发权限事件。

## 后果

- 未知模组方块实体无需专用库存提取适配。
- 某些拒绝 FakePlayer 或只监听私有权限接口的模组可能阻止破坏，或无法获得完整兼容。
- 大规模挖掘可能产生大量掉落实体，必须计入性能基准。
