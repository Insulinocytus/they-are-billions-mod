# ADR-0005：以持久化标记区分原版 Zombie 中的尸潮成员

- 状态：已接受
- 日期：2026-09-06

## 背景

首版需要复用原版 Zombie 的渲染、网络同步、属性与存档兼容性，同时避免改变命令、刷怪笼及其他模组显式创建的 Zombie。

## 决策

- 不注册自定义实体；模组生成真正的原版 `Zombie`，并为尸潮成员写入持久化标记。
- 导航、挖掘、距离分层、无死亡掉落和区块票据只作用于仍带标记的成员。
- 白天密度与阳光清理仍作用于所有普通 `Zombie`，沿用既有豁免规则。
- 尸潮成员被命名后移除标记，恢复原版行为、不再申请票据，但仍占普通 Zombie 总量预算。

## 后果

- 移除模组后实体仍能作为原版 Zombie 被世界读取。
- 其他模组若替换或深度修改原版 Zombie AI，可能与尸潮成员的行为注入冲突。
- 命名可以形成不产生新尸潮的“伪和平”，但不会使实体总量突破配置预算。
