# ADR-0007：保持平台桥轻薄并同步计算首版路径

- 状态：已接受
- 日期：2026-09-06

## 背景

原版 PathFinder 依赖活的实体与世界状态，不能安全地直接放入工作线程。Fabric 与 NeoForge 对 FakePlayer、区块票据和部分事件提供不同接口。

## 决策

- `common` 包含尸潮、分组、预算、导航、挖掘、清理、GameRule、命令与通用 Mixin。
- `fabric` 与 `neoforge` 仅包含各自的 FakePlayer、区块票据及生成/破坏事件桥。
- 首版不创建自有线程池；在服务器主线程错峰计算原版路径并缓存不可变路线模板。
- 未来只有在实现不可变世界快照上的流场时才引入 Worker，并始终回到服务器线程校验和应用结果。

## 后果

- 首版没有异步世界访问风险。
- 平台差异集中在少量适配代码中。
- 如果主线程错峰与缓存仍无法达到性能目标，需要以性能分析结果为依据重新审议流场，而不是直接异步调用原版 PathFinder。
